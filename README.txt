ДОМ ПОД ПРИСМОТРОМ / QAROVDAGI UY — сайт только на HTML + CSS (без JavaScript)

ЗАПУСК
  Откройте index.html двойным кликом (сервер не нужен).
  Для интернета: загрузите СОДЕРЖИМОЕ этой папки в корень репозитория GitHub Pages.

СТРУКТУРА
  index.html, why.html, services.html, how.html, viewer.html, contact.html  — русский
  uz/ (те же 6 страниц)                                                      — узбекский
  css/style.css   — все стили и анимации
  audio/ambient.wav — фоновая музыка (кнопка Play в шапке)
  models/         — сюда кладите фото своих объектов

ЯЗЫК
  Переключатель RU / UZ в шапке — это ссылки между русской и узбекской версией страницы.

3D-ОБЪЕКТ (viewer.html и uz/viewer.html)
  Положите фото объекта со всех сторон в models/ (cat-1.jpg ... cat-8.jpg).
  В viewer.html найдите блоки «МОЙ ОБЪЕКТ 1/3, 2/3, 3/3», уберите комментарии и впишите имена файлов.
  Повторите то же в uz/viewer.html.
